# PeakTalk Remotion

Тестовые Remotion-ролики в визуальном стиле PeakTalk.

```bash
npm install
npm run studio
npm run still
npm run still:logo
npm run still:simulation
npm run still:simulation:late
npm run render
npm run render:logo
npm run render:simulation
```

Композиции:

- `PeakTalkBars`: анимированная диаграмма, 1920x1080, 30 fps, 6 секунд.
- `PeakTalkLogo`: анимированный логотип на основе `frontend/public/logo_svg.svg`, 1920x1080, 30 fps, 5.5 секунд.
- `PeakTalkSimulationMockup`: видео-мокап внутреннего экрана симуляции PeakTalk, 1920x1080, 30 fps, 12 секунд.

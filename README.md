# 🎙️ PeakTalk — AI Trainer for Public Speaking

**PeakTalk** — это B2C SaaS решение, помогающее готовиться к публичным выступлениям (питчи, собеседования, презентации) с помощью умного текстового AI-тренера.

## 🚀 Основные возможности
- **Анализ контента**: Загрузка документов (PDF/Docx) и извлечение ключевых тезисов.
- **AI-Симуляции**: Текстовые Q&A сессии с каверзными вопросами от разных персонажей (Инвестор, HR, Скептик).
- **Internal Monologue**: AI-тренер «думает» перед тем как задать вопрос, разрабатывая стратегию тренировки.
- **Аналитика и фидбек**: Разбор сессии, оценка ответов и советы по улучшению.

## 🛠 Технологии
- **Frontend**: Next.js 15, TypeScript, Tailwind CSS, Framer Motion, Zustand.
- **Backend**: Python 3.12, FastAPI, PostgreSQL, SQLAlchemy.
- **AI**: Gemini 1.5 Flash.
- **Storage**: Supabase Storage.

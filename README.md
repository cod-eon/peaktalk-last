# PeakTalk

**PeakTalk** — B2B SaaS-платформа для тренировки сложных рабочих коммуникаций.  
Продукт помогает командам готовиться к защите инициатив, QBR, переговорам, инвест-спичам, конфликтным обсуждениям и другим high-stakes разговорам через текстовый AI-стресс-тест.

## Что уже есть в проекте

- **Документы:** загрузка PDF/DOCX/TXT или создание текстового документа прямо в системе.
- **Draft-анализ:** создание черновиков и AI-анализ текста через Gemini с улучшенной версией и структурированным feedback.
- **Simulation engine:** запуск AI-сессий с персонажами и уровнем давления, хранение истории диалога и internal reasoning.
- **Skill evaluation:** оценка ответов по метрикам вроде ясности, аргументации, структуры и стрессоустойчивости.
- **Projects:** объединение документов и симуляций в проект подготовки к конкретному событию.
- **Billing:** планы Starter / PRO / Team, лимиты использования, интеграция с YooKassa.

## Продуктовый тезис

PeakTalk не пытается быть “AI для публичных выступлений вообще”.  
Его рабочее ядро уже сейчас ближе к **AI-тренажеру защиты решений под давлением**:

- защита бюджета перед руководителем;
- сложный апдейт стейкхолдерам;
- клиентский QBR;
- инвест-коммуникация;
- жёсткий feedback conversation;
- внутренняя защита стратегии или инициативы.

Ключевая ценность не в генерации красивого текста, а в том, чтобы заранее вскрыть слабые места аргументации и натренировать реакцию на неудобные вопросы.

## Технологии

- **Frontend:** Next.js 16, React 19, TypeScript, Tailwind CSS, Framer Motion, Zustand, TanStack Query
- **Backend:** Python 3.12, FastAPI, SQLAlchemy
- **DB / Storage:** PostgreSQL, Supabase Storage
- **AI:** Gemini API
- **Infra:** Nginx, Docker Compose, rate limiting, request logging

## Ограничения MVP

- Только текстовый формат: без аудио, без видео, без биометрии.
- Основной сценарий: подготовка к рабочим коммуникациям, а не массовый consumer speech-coaching.
- Продукт ещё в стадии активной сборки, поэтому часть старых документов могла содержать устаревший B2C-нарратив.

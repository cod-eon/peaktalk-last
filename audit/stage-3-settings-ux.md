# Этап 3 — Settings: человеческие формулировки + убрать дубль «Биллинг»

## Цель
Заменить техно-жаргон в настройках на понятные пользователю формулировки. Убрать вкладку «Биллинг» из settings (она дублирует полноценную страницу /billing).

## Контекст
Страница настроек использует формулировки вроде «Токены не совпадают» (для пароля), «Длина токена < 8», «Конфигурация доступа обновлена» — это пугает и путает обычного B2B-пользователя.

### 3.3 Убрать вкладку «Биллинг» из settings

Вкладка «Биллинг» в settings показывает `ComingSoonTab`, при этом существует полноценная страница `/billing`. Это путает.

**Файл:** `frontend/src/app/(dashboard)/settings/page.tsx`, строка ~16

```ts
// Текущее:
const TABS = [
  { id: 'profile', label: 'ПРОФИЛЬ', icon: User },
  { id: 'security', label: 'БЕЗОПАСНОСТЬ', icon: Shield },
  { id: 'notifications', label: 'УВЕДОМЛЕНИЯ', icon: Bell },
  { id: 'billing', label: 'БИЛЛИНГ', icon: Wallet },
];

// Замена:
const TABS = [
  { id: 'profile', label: 'ПРОФИЛЬ', icon: User },
  { id: 'security', label: 'БЕЗОПАСНОСТЬ', icon: Shield },
  { id: 'notifications', label: 'УВЕДОМЛЕНИЯ', icon: Bell },
];
```

Также удалить:
- `Wallet` из импорта lucide-react (строка ~5) — проверить, что не используется в другом месте
- JSX-блок `{activeTab === 'billing' && ...}` (~строка 294–296)

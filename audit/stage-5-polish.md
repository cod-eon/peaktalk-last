**Файл:** `frontend/src/app/onboarding/page.tsx`, строки ~89–109

```tsx
{step === 3 && (
  <div className="absolute inset-0 pointer-events-none flex items-center justify-center z-0">
    {[...Array(20)].map((_, i) => (
      <motion.div
        key={`confetti-${i}`}

      />
    ))}
  </div>

```

Финальный шаг (success state) останется без изменений — зелёная галочка + карточки выбора действий достаточны.

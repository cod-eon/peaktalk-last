# MVP boundaries

## In scope

- Preparation for a high-stakes initiative, roadmap, or budget defense.
- Weak-point discovery, text-based adversarial simulation, optional voice input,
  and a Defense Brief.
- A self-serve professional B2C experience.

## Explicit non-goals

- Diction or speech production training.
- Voice simulation or voice-to-voice roleplay.
- Speech-quality, pronunciation, or confidence scoring.
- Generic confidence coaching.
- Job interviews or cold sales.
- Mass-market self-improvement.
- Achievements, streaks, badges, or infantilized gamification.
- LMS, team, or enterprise features before individual value is demonstrated.

Any change to these boundaries is a product decision, not an implementation
detail.

# PeakTalk — Browser Flow Checklist 2026-04-21

**Цель:** Ручная проверка критических сценариев dashboard-зоны после фаз 1-4 плана

## Критические сценарии для проверки

### Сценарий 1: Новая системная симуляция
1. Открыть `/simulation`
2. Выбрать вкладку `Системные`
3. Выбрать роль (инвестор)
4. Выбрать уровень давления
5. Выбрать индустрию (или оставить пустой)
6. Нажать `Новая тренировка`
7. ✅ Проверить: открылась сессия `/simulation/[id]`
8. ✅ Проверить: персона = инвестор, уровень давления совпадает
9. ✅ Проверить: состояние сессии = active

---

### Сценарий 2: Новая кастомная симуляция
1. Открыть `/simulation`
2. Выбрать вкладку `Мои персоны`
3. Выбрать кастомную персону
4. ✅ Проверить: шаг уровня давления СКРЫТ (согласно плану)
5. ✅ Проверить: показывается read-only уровень сложности персоны
6. Нажать `Новая тренировка`
7. ✅ Проверить: открылась сессия `/simulation/[id]`
8. ✅ Проверить: кастомная персона выбрана корректно
9. ✅ Проверить: в persona_config правильная персона

---

### Сценарий 3: Симуляция из встречи
1. Открыть `/meetings`
2. Создать встречу (если нет активной)
3. Нажать `Подготовиться`
4. ✅ Проверить: открылся `/simulation?meeting=[id]`
5. ✅ Проверить: meetup данные предзаполнены
6. ✅ Проверить: шаг индустрии можно менять
7. ✅ Проверить: смена персоны разрешена
8. ✅ Проверить: связь с встречей сохранена

---

### Сценарий 4: Продолжение активной подготовки
1. Создать встречу, начать подготовку (симуляция активна)
2. Вернуться на `/meetings`
3. ✅ Проверить: кнопка = `Продолжить подготовку`
4. ✅ Проверить: переход ведёт в активную сессию `/simulation/[id]`

---

### Сценарий 5: Завершенная симуляция → отчет

2. Перейти в историю, нажать на карточку
3. ✅ Проверить: открылся `/simulation/[id]/report`
4. ✅ Проверить: конфетти при балле 8+
5. ✅ Проверить: метрики отображаются корректно
6. ✅ Проверить: popover с комментариями работает по клику

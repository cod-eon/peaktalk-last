## Принятые решения (Decision Log)

### DL-1: Подход к исправлениям
**Решение:** Подход 2 — глубокая переработка affected-зон с бэкенд-изменениями
**Почему:** Нужно смотреть в будущее, строить правильную архитектуру связей

### DL-2: Цветовые классы — прямые hex
**Решение:** Использовать прямые hex (`text-[#E8600A]`) вместо CSS-переменных Tailwind
**Почему:** Tailwind v4 не всегда генерирует utility для кастомных CSS-токенов; hex надёжнее

## Детали реализаций

### Секция 1: Цвета
**Файлы:** dashboard/page.tsx, meetings/page.tsx, simulation/page.tsx, lib/constants/personas.ts
**Что сделано:** Все `blue-*` классы заменены на оранжевые аналоги (#E8600A, #FEF3E8, #F9BD8E, #B04A08, #D4570A, #F29555)

### Секция 2: Встречи → Симуляция
**Бэкенд:**
- Новый endpoint `POST /meetings/{meeting_id}/prepare-simulation` — маппит тип встречи на роль, проверяет существующие сессии
- `POST /simulation/start` теперь принимает `meeting_id` — привязывает к встрече
**Фронтенд:**
- `simulation/page.tsx`: обработка `?meeting=` — вызывает prepare endpoint, редиректит на setup с предвыбранной ролью
- При старте передаёт `meeting_id` в payload

### Секция 3: Прогресс
**Файл:** progress/page.tsx
**Что сделано:** Убраны SkillBadge (strongest/weakest) и их секция. TrajectoryTimeline заменён на компактный LastSessions (последние 5 сессий — дата, score, мини-бар).

### Секция 4: Персоны → Симуляция
**Бэкенд:**
- `GET /simulation/personas` расширён: добавлено поле `user_personas` с пользовательскими персонами
**Фронтенд:**
- `personas/page.tsx`: «Использовать в симуляции» превращён из `<span>` в кликабельную кнопку с редиректом на `/simulation?persona={id}`
- `simulation/page.tsx`: добавлена секция «Ваши персоны» в setup view. Обработка `?persona=` параметра. `isReady` учитывает выбор пользовательской персоны.

### Секция 5: ShareCard
**Файл:** ShareCard.tsx
**Что сделано:** Добавлен `import { toast } from 'sonner'`, `console.error` заменён на `toast.error`. html2canvas уже был установлен.

### Секция 6: PDF шпаргалки
**Файл:** PrepCard.tsx
**Что сделано:** Добавлена функция `handlePrintPdf` с scoped print CSS (печатает только `#prep-card-ui`). Кнопка «Скачать PDF» вызывает её вместо bare `window.print()`.

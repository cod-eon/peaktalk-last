# Product Copy

Use this skill for user-facing wording. Read the relevant product model and flow specification so the copy serves the intended user and decision.

## Process

1. Identify the moment, audience, user concern, and action the text must support. Preserve the existing behavior and information architecture unless the task explicitly changes them.
2. Prefer plain, specific language over hype, generic confidence claims, or inflated promises. Keep PeakTalk positioned around preparation for difficult professional communication.
3. Offer a small number of materially different variants only when a choice is needed; explain the trade-off and recommend one.
4. Do not invent outcomes, customer proof, guarantees, pricing, or product capabilities. Mark missing facts instead of filling them in.
5. Verify the rendered text, localization/length constraints, and relevant tests or lint. For an isolated copy edit, a full task contract is usually unnecessary; use one if wording changes behavior or product claims.

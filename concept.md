# PeakTalk — Концепция проекта

> **«Один разговор меняет всё»** · *«Твой голос сильнее резюме»*

---

## Суть

**PeakTalk** — B2C SaaS AI-тренер для развития коммуникативных навыков: подготовка к IT-собеседованиям, уверенная речь, устранение слов-паразитов, публичные выступления.

**Проблема:** Знаний достаточно — не хватает умения говорить. Друзья скажут «всё норм», рекрутер просто откажет. Объективной обратной связи нет.

**Решение:** Записал видео → AI проанализировал → получил детальный отчёт с метриками, таймлайном и конкретными рекомендациями → тренируешься → видишь прогресс.

---

## Целевая аудитория

Студенты и junior-специалисты, готовящиеся к собеседованиям или желающие говорить чётче и увереннее.

---

## Путь пользователя

1. **Опросник** → персональный план обучения
2. **Видео-упражнения** — отработка навыков с записью себя
3. **Голосовые симуляции** — практика с AI-интервьюером в реальном времени (WebSocket)
4. **Отчёт Gemini API** — таймлайн, метрики уверенности/стресса, слова-паразиты, рекомендации
5. **Дашборд** — динамика навыков, следующий шаг, streak

---

## Что анализируется

- Эмоции и уверенность (по таймлайну видео)
- Темп речи, паузы, интонация
- Слова-паразиты («ну», «э-э-э», «как бы», «типа»)
- Зрительный контакт с камерой, язык тела
- Score-балл + сравнение с предыдущими попытками

## Технический стек

| Слой | Технологии |
|---|---|
| Frontend | Next.js 15 (App Router) · TypeScript · Tailwind CSS · Framer Motion · TanStack Query · Zustand · next-pwa |
| Backend | Python 3.12 · FastAPI · Celery · Redis |
| БД / Хранилище | PostgreSQL · Supabase Storage → Яндекс Cloud S3 (сжатые видео) |
| AI | Gemini API (транскрипция, анализ речи, генерация фидбека, голосовые симуляции) |
| Инфра | DDoS-Guard → Яндекс CDN → Nginx → FastAPI · slowapi · 152-ФЗ |
| Деплой | PWA (без App Store) · Web Push уведомления |

---

## Архитектура

```
[Next.js 15 PWA]
      ↕ HTTP/REST
[FastAPI — API, auth, CRUD]
      ↕ Redis (очередь задач + кэш статусов)
[Celery AI-воркер]  ←→  Gemini API
      ↕
[PostgreSQL]  [Supabase / Яндекс S3]
```

**Видео:** анализ асинхронный (до 5 мин) → сжатие до 360p через ffmpeg → оригинал удаляется → уведомление (Web Push + badge в приложении).

## Ключевые API

```
POST /onboarding              → план обучения
GET  /dashboard               → метрики + следующее упражнение
POST /exercises/{id}/submit   → загрузить видео → Celery-задача
GET  /reports/{id}            → результат анализа
WS   /simulations/{id}        → реалтайм голосовая симуляция
```

---

## Отличия от конкурентов

1. **Фокус на IT-собеседованиях** — не просто анализ речи, а специфика интервью
2. **Русскоязычность** — полностью RU с учётом культурного контекста
3. **Реалтайм симуляции** — практика с AI-интервьюером голосом, не текстом
4. **PWA** — устанавливается на телефон, пуш-уведомления без App Store
5. **Прогресс-трекинг** — динамика навыков в динамике, не просто один отчёт
